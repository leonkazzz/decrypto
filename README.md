# 密语控制台 · 红蓝线下主持人版

Decrypto 类线下猜词游戏的主持人工具。纯静态网站：不需要注册、数据库或服务器，数据只保存在访客自己的浏览器里。

## 功能

- 内置 3141 个不重复的常用中文词（15 个类别），只收一听就懂、好联想的词，可在 `words.js` 中增删。
- 红蓝两队各 4 个词，同局 8 词绝不重复；互相包含的词（如「足球 / 足球鞋」）也不会同局出现；最近 5 局用过的词优先避开。
- 准备阶段：任意一张词卡可单独重抽或手动修改，其余 7 张不变。
- 点「正式开始」后 8 个密词和抽词模式全部锁定。
- 每轮两队各自生成三位密码（数字 1–4 不重复，使用浏览器加密随机数）。
- 密词默认遮盖，点「显示」查看；密码需要按住才显示，松手即隐藏；切换队伍、刷新页面、切到后台时自动遮盖。
- 回合管理：最多 8 轮；点圆点记录拦截成功 / 传达失误并自动判定胜负；往轮密码记录在「设置」里。
- 主屏只保留游戏必需的操作，词库、存档、规则都收在右上角「设置」中。
- 自定义词库：手动添加、批量粘贴、从 .txt/.csv 文件导入、逐个删除、清空、导出。
- 本地自动存档；可导出/导入主持人存档 JSON 换设备继续。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `style.css` | 样式（深色、红蓝配色、手机优化） |
| `words.js` | 内置词库 |
| `engine.js` | 抽词、重抽、修改、密码等纯规则 |
| `app.js` | 界面交互与本地存档 |
| `engine.test.cjs` | 规则测试，运行 `node --test` |
| `.nojekyll` | 让 GitHub Pages 原样发布文件 |

直接双击 `index.html` 也能离线使用。

## 修改词库

编辑 `words.js`，在对应类别的数组里增删词语（每个词不超过 18 个字符，全库不能重复），然后运行 `node --test` 检查。

> 非官方工具，仅参考 Decrypto 玩法，不使用原版品牌视觉或专属词库。备份 JSON 含秘密词和密码，请不要发给玩家。
